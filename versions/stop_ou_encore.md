# Version stop ou encore

- Dans cette version, les personnages possèdent les mêmes caractéristiques
- La seule chose qui change concerne la résolution des duels
- Lorsque les deux joueurs ont choisi leurs personnages, à tour de rôle et jusqu'à ce que les deux s'arrêtent, ils vont piocher une carte dans le tas des cartes Puissance
- Une carte puissance a deux caractéristique : une puissance entre 0 et 2, et des points de malus entre 0 et 2
- Le principe est de faire un stop ou encore : la puissance totale du personnage est égale à sa puissance de base plus l'ensemble des puissances des cartes puissance piochées par son joueur
- Cependant, si la somme des points de malus sur les cartes piochées devient égale ou supérieure à trois, alors tous les points de puissance sont annulés
- Lors des tours de pioche, un joueur peut choisir à tout moment de s'arrêter
- Si la somme des malus de ses cartes est supérieure ou égale à trois, il est obligé de passer
- Un joueur qui passe ne peut plus piocher de nouvelle carte pour la suite du combat
- Voici les cartes puissances et leurs nombre :
  - 3 x Destin : 2 Puissance, 0 Malus
  - 7 x Chance : 1 Puissance, 1 Malus
  - 7 x Péripétie : 0 Puissance, 0 Malus
  - 3 x Malheur : 0 Puissance, 2 Malus
